**الإصدار:** 2.3.0 · **الفرع:** `main` عند `d3e3bda` · **تاريخ التقييم:** 2026-10-31
· **المنهج:** فحص مباشر للشيفرة + تشغيل فعلي (لا ادّعاء من README وحده).

هذا تقييم لكامل المشروع — لا للشخصيات وحدها — يغطّي: المعمارية، البوابات الأربع،
المكوّن العصبي، المعرفة، الإدراك المستقل، الشخصيات، الأمان، والتوثيق — مع نقاط
القوة والقصور وخطة التطوير.

## 1. الخلاصة التنفيذية

المشروع **هندسيًا من الطراز الأول** (اختبار، أنواع، بوابات، أمان، توثيق)،
و**معماريًا طموح** (بنية إدراكية رمزية + استرجاع + استدلال + مواهب محلية/سحابية).
قوّته الحقيقية في **المسار الرمزي/الاسترجاعي** (الرسم البياني + الاسترجاع +
التركيب + الاستدلال الموصول). أكبر فجوة قابلة للقياس تبقى **النموذج اللغوي
المدرَّب داخل المشروع**: يعمل لكن مخرجاته طلاسم.

أربع نتائج قياسية تحدّد الصورة:

| البُعد | الحالة | الدليل (مقيس الآن) |
|---|---|---|
| **الجودة الهندسية** | ممتازة | 5377 اختبارًا ناجحًا، 12 فشلًا **بيئيًا فقط**، ruff نظيف، mypy 859 ملفًا بلا خطأ، تقييم PASS |
| **المسار الرمزي (عربي)** | ممتاز | إجابة عربية بمتن عربي + استشهادات، 0 معرّف إنجليزي متسرّب، **0.009–0.166 ث** لكل سؤال |
| **الإدراك المستقل + الشخصيات** | يعمل ومقيس | 28 دورة إدراكية، 126 فكرة، 2109 سؤالًا، شخصيات 84% |
| **المسار العصبي (النموذج)** | **ضعيف وظيفيًا** | 842,624 معاملًا، tokenizer بايتي، مخرج: `Mud wh) is discretizated a magnetism decision.` |

## 3. نقاط القوة

### 3.1 المعمارية (ممتازة)
- **فصل نظيف:** `core/` (الإدراك)، `ml/` (التعلّم)، `ai/` (الأفواه)، `gui/`/`cli/`
  (سطحان متطابقان لنفس المنطق)، `ingest/`، `companion/`، `hakeem/`، `cognition/`،
  `storage/`، `evaluation/`.
- **كل موهبة اختيارية معزولة بـseam قابل للحقن** ⇒ اختبار بلا أوزان ولا شبكة ولا عرض.
- **لا قاعدة بيانات أو رسم بياني ثانٍ:** كل الطبقات الجديدة تعمل على الرسم نفسه.

### 3.2 البوابات الأربع (ممتازة)
- `pytest` + `ruff` + `mypy` + `evaluation` كأمر واحد، والانحدار **يُكتشَف آليًا**
  (`RegressionReport`) — وقد كشف انحدار `semantic_separation` في المرحلة 50.
- 52 مقياسًا محجوزًا، منها بوابات **سلوكية** لا مجرد اتساق: `answer_path_accuracy`
  تشغّل مسار الإجابة الحقيقي، و`controller_causal_accuracy` تقيس *التوصيل* لا
  *الماشي*، و`arabic_readable_body_accuracy` تمنع تسرّب أي معرّف إلى المتن.

### 3.3 المسار الرمزي والعربي (ممتاز)
- إجابة عربية **بمتن عربي** + استشهادات + طبقات استدلال (خطة، توصية، حكم، تشبيه،
  زمني) موصولة فعليًا، وبسرعة **4 مللي ثانية** للسؤال.
- تغطية أسماء عربية **100%**، و0 معرّف متسرّب.

### 3.4 الأمان (ممتاز)
- **رمل أدوات deny-by-default** بأربع طبقات: قائمة سماح، حبس الجذر، فصل قراءة/كتابة،
  بوابة قدرة + **موافقة بشرية** للأدوات الخارجية.
- **عزل ذاكرة بنيوي:** `learning_isolation` يرفض الوصول قبل حلّ أي مسار؛ Natasha
  خاصة ومُختبَرة ببوابة `character_isolation_accuracy = 1.0`.
- **بوابة رسوخ** تفشل مغلقة، و**موافقة بشرية** لكل تنزيل/استدعاء خارجي، وتنقيح أسرار.
- **0 `eval`/`exec`** في `core`/`ai`؛ استخدام واسع لـ`best_effort` (63 موضعًا) بدل
  الابتلاع الصامت.

### 3.5 الإدراك المستقل (يعمل ومقيس)
- 19 وحدة إدراك، **28 دورة**، **126 فكرة**، بنك **2109 أسئلة**، جلسة دراسة ذاتية
  **200 سؤال** (100% أُجيب من دليل)، وتقييم موثوقية **0.815**.
- التدريب التدريجي (SMOKE/QUICK/STANDARD/FULL) مع بوابة نسخ/تراجع — لا تعديل في المكان.

### 3.6 الشخصيات (84%)
- 8 شخصيات، بنية موحّدة (config + registry + غلاف شفّاف)، كل واحدة تعمل بأوزان حقيقية
  على القرص، واستدعاء **مرتّب بالصلة**، وحقائق **تتلاشى تدريجيًا** بمنحنى حقيقي.

### 3.7 التوثيق (نادر في مشروع بهذا الحجم)
- 11 مستندًا (3,894 سطرًا) تسجّل كل مرحلة بدليلها وبانحداراتها المُصلَحة، و`AGENTS.md`
  (5,757 سطرًا) هو ذاكرة المشروع الحيّة.

## 4. نقاط القصور (مرتّبة بالخطورة، كلها بأدلة)

### قصور 1 (الأخطر) — النموذج اللغوي المدرَّب غير قابل للاستخدام
مخرج طلاسم، والسبب مركّب: **842K معاملًا + tokenizer بايتي + 4000 خطوة**. الأثر:
واجهة «من النموذج المدرَّب» موجودة ومختبَرة لكن مخرجها غير مفيد.
**التغلّب:** tokenizer BPE + سعة `capable` + إعادة تدريب على المدوّنة العربية (الآن 24.4%).

### قصور 2 — الـtokenizer المنشور بايتي لا BPE
الكود يدعم BPE (`ml/llm/bpe.py`، `--tokenizer-kind bpe`) لكن المنشور `kind=byte`.
**التغلّب:** إعادة كتابة الـcheckpoint بـBPE.

### قصور 3 — قاعدة المعرفة الضخمة غير مبنية
0 شظية، 0 فهرس. **التغلّب:** `python -m cli knowledge build` + `build-index`.

### قصور 4 — القطع المدرَّبة قديمة (2026-10-08)
قبل متن العربية (المرحلة 50)، وإعادة التدريب بطيئة على CPU. **التغلّب:** تدريب
تدريجي على مراحل عبر `--resume`/`--llm-shards`.

### قصور 5 — جودة المواهب الاختيارية غير مقيسة هنا
كل الأصوات والنماذج المحلية غير متحقَّق من جودتها (تُختبَر بالـseam فقط) بسبب غياب
Tk/الصوت/الأوزان في هذه البيئة. **التغلّب:** تركيب الإضافات في CI.

### قصور 6 — 12 اختبارًا غير محيّد عن البيئة/البيانات
`test_model_manager_service` و`test_model_selection` تفشل عند وجود بيانات محلية
مزروعة (تحتاج `FAYD_DATA_DIR` نظيفًا) — **ثغرة عزل اختبار حقيقية** (لا تخصّ
الشيفرة، لكنها تُربك التشغيل المحلي). **التغلّب:** فرض `tmp_path` صريح في هذه الملفات.

### قصور 7 — مقياس جودة الإجابة الذاتي
كل مقاييس `accuracy` = 1.0 (بوابات اتساق ذاتي)، فلا يوجد مقياس محجوز لجودة
مُحكَّمة بشرية أو للطلاقة أو لمعدّل التلفيق مقابل حقيقة خارجية ⇒ خطر الإفراط في
التوفيق مع البذور. **التغلّب:** مقياس جودة محجوز (طلاقة/رسوخ/تلفيق).

### قصور 8 — ذاكرة الشخصيات تحتاج حجمًا فعليًا
72% لأنها تعكس مخزنًا مبذورًا؛ السقف يحتاج تفاعلًا حقيقيًا. **التغلّب:** توسيع البذرة
أو استخدام فعلي.

### قصور 9 — Jarvis تطويره 56%
فمه استرجاعي بلا نموذج قابل للتبديل. **التغلّب:** تمكين تبديل نموذج للفم الاسترجاعي.

## 7. الحكم النهائي

المشروع **هندسيًا من الطراز الأول** و**معماريًا طموح**، وقوّته الحقيقية في
**الرسم والاسترجاع والاستدلال** لا في النموذج. الفجوة القابلة للقياس اليوم ليست في
«هل يوجد؟» بل في «هل يعمل جيدًا؟»:

- **الرمزية والعربية:** تعمل ممتازًا (سرعة مللي ثانية، متن عربي، استشهادات، 0 تسرّب).
- **الإدراك المستقل:** يعمل ويقيس نفسه بأمانة (0.815).
- **الشخصيات:** 84% بأوزان حقيقية وذاكرة حيّة واستدعاء بالصلة.
- **النموذج العصبي:** لا يتكلّم — وهذه أكبر فجوة، وكل مكوّنات إصلاحها جاهزة.
- **المعرفة الضخمة:** غير مبنية هنا (بيئي).
- **صدق القياس:** كل المقاييس ذاتية الاتساق ⇒ تحتاج مقياس جودة محجوزًا.

**الاتجاه الصحيح:** إصلاح النموذج (BPE + سعة + إعادة تدريب) ← مقياس جودة محجوز ←
قاعدة المعرفة الضخمة. كل البنية تحت هذا جاهزة ولا تحتاج إعادة كتابة.
