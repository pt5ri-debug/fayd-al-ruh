# Optional: Qwen3-TTS speech synthesis (the [qwen-tts] extra).
#
# Install with:  python -m pip install -r requirements-qwen-tts.txt
#
# **Qwen3-TTS** reads chat text aloud, expressively and naturally, across its ten
# languages. It runs **locally** in this process -- nothing is sent off the
# machine. The base install needs none of this: the import is lazy and the app
# reports the real next step when it is absent.
#
# **Qwen3-TTS does not speak Arabic.** Its ten languages are Chinese, English,
# Japanese, Korean, German, French, Russian, Portuguese, Spanish, and Italian.
# For Arabic, use the system engine or the natural local Piper voice
# (``requirements-piper.txt``), which does speak Arabic.
#
# ``transformers`` is deliberately *not* listed here. ``qwen-tts`` pins the exact
# version it was built against (``transformers==4.57.3``), and restating a looser
# ``transformers>=4.40`` alongside that pin is what made pip backtrack through
# every older ``transformers`` -- including the releases that cap ``numpy<2.0`` --
# until it tried to *build* numpy 1.26.4 from source, which fails on Windows with
# a long-path ``OSError`` (and on any machine with no compiler). Letting
# ``qwen-tts`` own the pin resolves straight to a modern numpy with a wheel.
#
# NOTE: ``qwen-asr`` and ``qwen-tts`` pin *different* exact ``transformers``
# versions (4.57.6 vs 4.57.3), so the two cannot share one environment. Install
# this file for speech synthesis, ``requirements-qwen-asr.txt`` for the
# microphone -- not both. ``core/qwen_speech.py`` reports whichever is present.
#
# The model weights are a *separate* one-time, human-approved download:
#     python -m cli qwen-tts download --approve      # ~3.4 GB (1.7B) or ~1.2 GB (0.6B)
# or drop a model folder into the data/qwen-speech folder. The model is Qwen's
# own, released under Apache-2.0.
