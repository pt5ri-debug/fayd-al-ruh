# Optional: Banner, the Presentation Studio's local language model.
#
# Install with:  python -m pip install -r requirements-banner.txt
#
# Banner is the same local Qwen3 model the Presentation Studio already drafts
# with, promoted to a first-class "mouth" (see `core/banner.py`). It therefore
# shares the Studio's `[presentation]` runtime and its `data/presentation` model
# folder, so the pins live in one place and this file only includes them -- there
# is nothing extra to install and no second copy of the weights.
#
# The model weights are a *separate* one-time, human-approved download:
#     python -m cli banner download --approve
# or drop any `.gguf` file into the data/presentation folder. The base install
# needs none of this; the import is lazy and the app reports clearly when absent.
-r requirements-presentation.txt
