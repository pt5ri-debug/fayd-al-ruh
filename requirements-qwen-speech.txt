# Optional: the Qwen3 speech models (ASR and TTS) for every chat interface.
#
# Install with:  python -m pip install -r requirements-qwen-speech.txt
#
# This pulls a CPU ``torch`` plus Qwen's own inference packages, so a chat can
# transcribe speech with **Qwen3-ASR** (52 languages, including Arabic) and read
# text aloud with **Qwen3-TTS** (expressive, ten languages -- it does *not* speak
# Arabic). Both run **locally** in this process: nothing is sent off the machine.
#
# ``qwen-asr`` provides the ASR model class (``Qwen3ASRModel``); ``qwen-tts``
# provides the TTS model class (``Qwen3TTSModel``). ``transformers`` is pulled in
# by ``qwen-asr`` and is listed here so the ASR path works even when a user
# installs only part of the extra.
#
# The model weights are a *separate* one-time, human-approved download:
#     python -m cli qwen-asr download --approve      # ~3.4 GB (1.7B) or ~1.2 GB (0.6B)
#     python -m cli qwen-tts download --approve      # ~3.4 GB (1.7B) or ~1.2 GB (0.6B)
# or drop a model folder into the data/qwen-speech folder. The base install needs
# none of this; the imports are lazy and the app reports clearly when they are
# absent. Both models are Qwen's own, released under Apache-2.0.
torch>=2.2
transformers>=4.40
qwen-asr
qwen-tts
